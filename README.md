Interactive To-Do List with LocalStorage

Project Description

An interactive To-Do List application developed using HTML, CSS, and JavaScript. It helps users manage their daily tasks easily.

Features

- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Save tasks using LocalStorage.
- Tasks remain saved after refreshing the page.
- Add tasks using the Enter key.

Technologies Used

- HTML
- CSS
- JavaScript
- DOM Manipulation
- Event Listeners
- LocalStorage

How to Run

1. Download the project file.
2. Open "todo_list_localstorage.html" in a web browser.
3. Add, complete, or delete tasks.

Learning Outcomes

- Understanding JavaScript DOM manipulation.
- Working with click and keyboard events.
- Managing application state.
- Using LocalStorage for data persistence.
